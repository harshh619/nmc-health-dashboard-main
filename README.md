# NMC Disease Surveillance Portal (v2.0.0)

Nagpur Municipal Corporation (NMC) Disease Surveillance and Real-Time Outbreak Monitoring Dashboard.

## Features
- **Real-Time Surveillance Map**: Interactive GIS spatial visualization with Ward-wise heatmap overlays.
- **Dynamic Analytics & Charts**: Interactive Recharts breakdown of disease distributions, demographic metrics, and temporal trends.
- **Advanced Filtering**: Multi-select filtering by Ward, Zone, Status, Gender, and custom Date Ranges.
- **Automated Weather Metrics**: Integrated Live Open-Meteo climate & rainfall telemetry for Nagpur.

## Local Development
```bash
npm install
npm run dev
```

## Production Build & Deployment
```bash
npm run build
```
This repository is optimized for one-click deployment on **Vercel**.
